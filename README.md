# FAME — превью сайта

Статический сайт для GitHub Pages. Все файлы лежат в корне репозитория.

## Как обновить
1. Add file -> Upload files -> перетащить новые файлы (index.html и медиа), заменить старые.
2. Commit changes.
3. Через ~30-60 сек изменения появятся по ссылке Pages.

Медиа-файлы имеют хэш в имени -> браузер кеширует их надолго; при обновлении заново скачиваются только изменившиеся.

Сайт закрыт от индексации (noindex + robots.txt): в поиске не найдётся, доступ только по прямой ссылке.
